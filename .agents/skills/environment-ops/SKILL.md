# Environment Operations Skill

Utiliza esta habilidad para gestionar los flujos de ejecución del entorno:

- **Up**: Levantar contenedores y servicios del entorno local o desarrollo.
- **Down**: Apagar contenedores y limpiar recursos activos.
- **Test**: Ejecutar la suite de pruebas automatizadas (pytest).
- **Deploy**: Desplegar servicios e infraestructura en Google Cloud Platform (Cloud Run, Cloud Functions, Pub/Sub).
